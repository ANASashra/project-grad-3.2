# Domain Vuln Scanner

أداة متكاملة لفحص الثغرات في النطاقات وتحليل أمان الشبكة.

## الميزات الرئيسية

- **فحص داخلي للشبكة** باستخدام nmap (معلومات IP، فحص المنافذ)
- **استخراج النطاقات الفرعية** باستخدام subfinder
- **فحص حالة النطاقات الفرعية** (HTTP/HTTPS/SSL) - اختياري
- **استعلام معلومات DNS** مع إظهار مختلف أنواع السجلات
- **جمع معلومات WHOIS** للنطاق المستهدف

## متطلبات التشغيل

- Python 3.6+
- nmap
- subfinder
- المكتبات المذكورة في الكود (requests, dns.resolver, etc.)

## طريقة الاستخدام

```bash
python3 backend/main.py
```

ثم اتبع التعليمات على الشاشة لإدخال النطاق المستهدف واختيار خيارات الفحص.
